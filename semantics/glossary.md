# Glossary

| Term | Meaning here |
| --- | --- |
| **GMV** (gross merchandise value) | `SUM(order_items.price + order_items.freight_value)` over completed orders, at **order-item** grain. |
| **Revenue** | `SUM(order_payments.payment_value)` over completed orders, at **order** grain. What customers paid, including freight. |
| **Gross vs net revenue** | `revenue` is **gross of refunds**. The V1 registry still maps phrasing such as "net sales" or "net revenue" to `revenue`, so an answer to a "net" question must state that refunds are not deducted. Refunds exist only in the **synthetic** `returns.refund_value`; any figure net of them must say it uses synthetic refunds. There is no governed net-revenue metric. |
| **Completed order** | `order_status NOT IN ('canceled', 'unavailable')`. |
| **AOV** (average order value) | Revenue over distinct completed orders. A **ratio**: decompose into numerator and denominator, never sum shares of it. |
| **Order vs order item** | An order has one or more items (`order_items.order_item_id`). Item counts and order counts differ. |
| **`customer_id` vs `customer_unique_id`** | `customer_id` is per order (99,441 rows); `customer_unique_id` is the person. Unique customers and segments use the latter. |
| **Complete period** | A month whose volume passes the completeness rule (`semantic/completeness.py`). On the real data the last complete month is **2018-08**; 2018-09, 2018-10 and 2016-09 are incomplete. |
| **Anchor period** | The last complete period a forecast is fitted on and projects from. |
| **Synthetic** | Generated by `scripts/synth/generate.py`, keyed to real ids. Never a measurement of the real business; always labelled. |
| **Layer** | `real`, `synthetic` or `mixed`, computed from the tables actually read. |
| **Conversion rate** | Orders per session, session-weighted: `SUM(sessions * conversion_rate) / SUM(sessions)`. Synthetic. |
| **Stockout rate** | Share of category-days with zero stock at day end. Synthetic. |
| **Return rate** | Returned delivered items over delivered items, by purchase date. Synthetic numerator over real denominator. |
| **Margin** | `(SUM(price) - SUM(unit_cost)) / SUM(price)`: real price, synthetic cost. |
| **Target attainment** | Real revenue over the synthetic `regional_targets.revenue_target`, per state and month. |
| **Elasticity** | The % change in units for a 1% change in price, estimated log-log from `price_history` and `inventory_daily`, controlling for promotions and competitor prices. Observational, not experimental; synthetic. |
| **Boleto** | A Brazilian bank-slip payment method. |
| **SLA breach** | `actual_days > promised_days` in `delivery_sla`. |
| **Confounder** | Something that moves with an effect but does not cause it. Each planted effect has one. |
| **Evidence grade** | 0-4 strength of a driver claim (`EVID-1`): concentration, co-movement, specificity; never causal without an experiment. |
